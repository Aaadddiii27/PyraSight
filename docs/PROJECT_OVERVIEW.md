# PyraSight — Project Overview

## 1. Introduction

PyraSight is a wildfire intelligence and decision-support prototype designed to combine machine learning, geospatial awareness, satellite thermal detections, and incident management into a unified application.

The project aims to provide an interactive environment where users can explore wildfire-related information, analyze environmental conditions, generate machine learning predictions, and manage fire-related incidents.

PyraSight integrates historical datasets and satellite detection records with a web-based dashboard.

## 2. Problem Statement

Wildfire monitoring and risk assessment involve analyzing multiple sources of information, including environmental conditions, historical fire records, and satellite observations.

When these sources are handled separately, it can be difficult to obtain a unified understanding of fire-related activity.

PyraSight addresses this problem by providing a centralized platform that combines:

- Historical wildfire data.
- Environmental feature-based machine learning.
- Satellite thermal detection visualization.
- Incident tracking and management.
- Reporting and alert management.
- Explainable machine learning outputs.

## 3. Project Objectives

The primary objectives are:

1. Develop a centralized wildfire intelligence dashboard.
2. Integrate historical wildfire datasets for machine learning.
3. Build models for fire and fire-danger classification.
4. Visualize NASA FIRMS VIIRS thermal detections geographically.
5. Provide interactive incident management.
6. Support report generation and alert-rule management.
7. Maintain application data using SQLite.
8. Provide model explainability through SHAP feature importance.
9. Maintain separate temporal and spatial model evaluation protocols.

## 4. System Modules

### 4.1 Command Center

The Command Center provides a dashboard overview of the application.

Key functionality:
- Active model information.
- FIRMS detection statistics.
- Detection activity trends.
- Application-level monitoring information.

### 4.2 Hazard Forecast

The Hazard Forecast module provides a prediction interface based on environmental input features.

Key functionality:
- Environmental feature input.
- Machine learning inference.
- Fire-danger probability.
- Danger-level classification.
- Model information.

The predictions are generated by trained models using the supplied input features.

### 4.3 Global Fire Map

The Global Fire Map provides an interactive geographic visualization of satellite thermal detections.

Key functionality:
- MapLibre-based interactive map.
- NASA FIRMS VIIRS detection records.
- Confidence-based marker visualization.
- Satellite filtering.
- Confidence filtering.
- Automatic map fitting to detection coordinates.
- Detection details on marker selection.

The displayed thermal detections are satellite observations and are not necessarily confirmed wildfire incidents.

### 4.4 Incident Explorer

The Incident Explorer provides functionality for managing fire-related incidents.

Key functionality:
- Incident listing.
- Incident detail inspection.
- Status updates.
- Analyst notes.
- Bookmarks.
- Incident editing.
- Incident deletion.

### 4.5 Reports and Alerts

This module supports application reporting and alert-rule management.

Key functionality:
- Fire activity reports.
- Detection summary reports.
- Model prediction reports.
- Incident summary reports.
- Report downloads.
- Alert-rule management.

## 5. Machine Learning Components

PyraSight contains three model artifact groups.

### 5.1 Algerian Fire Classification Model

- Algorithm: XGBoost.
- Dataset: Algerian Forest Fires dataset.
- Task: Fire versus no-fire classification.
- Input: Environmental and fire-weather features.

Held-out test results:

| Metric | Score |
|---|---:|
| Accuracy | 92.56% |
| Precision | 94.26% |
| Recall | 91.27% |
| F1 Score | 92.74% |
| ROC-AUC | 96.70% |
| PR-AUC | 95.73% |

### 5.2 Mesogeos Temporal Model

- Algorithm: XGBoost.
- Dataset: Mesogeos danger-forecasting dataset.
- Evaluation: Chronological group-aware split.
- Task: Fire-danger classification.

Held-out temporal test results:

| Metric | Score |
|---|---:|
| Accuracy | 79.51% |
| Precision | 67.37% |
| Recall | 75.21% |
| F1 Score | 71.07% |
| ROC-AUC | 86.84% |
| PR-AUC | 78.38% |

### 5.3 Mesogeos Spatial Model

- Algorithm: Random Forest.
- Dataset: Mesogeos danger-forecasting dataset.
- Evaluation: Spatial block split with a 25 km training buffer.
- Task: Fire-danger classification.

Held-out spatial test results:

| Metric | Score |
|---|---:|
| Accuracy | 77.93% |
| Precision | 62.28% |
| Recall | 60.05% |
| F1 Score | 61.15% |
| ROC-AUC | 81.40% |
| PR-AUC | 65.42% |

### 5.4 Model Explainability

SHAP is used to calculate and inspect feature importance for model interpretation.

It helps identify which input features contribute to model predictions.

The importance of a feature does not establish a causal relationship with wildfire occurrence.

## 8. Data Flow

The general application workflow is:

1. User interacts with the React frontend.
2. Frontend sends API requests to the FastAPI backend.
3. Backend processes requests and accesses the required services.
4. Machine learning services load trained model artifacts for inference.
5. Application records are stored through the SQLite data store.
6. API responses are returned to the frontend.
7. Frontend displays predictions, maps, incidents, reports, and dashboard information.

## 9. Database and Persistence

PyraSight uses SQLite for local application persistence.

Database location:

`backend/data/pyrasight.db`

Persistence has been tested across backend restarts for incidents, predictions, alert rules, and reports.

The local database is runtime data and should not be included in a public source-code repository.

## 11. Limitations

- The Algerian dataset has limited geographic and temporal coverage.
- Temporal and spatial Mesogeos evaluations use different test protocols.
- Their metrics are not directly comparable.
- Spatial validation and test locations are not fully independent.
- FIRMS thermal detections are not necessarily confirmed wildfires.
- Model predictions depend on historical training data and supplied environmental features.
- Operational real-time wildfire forecasting capability has not been established.

## 12. Intended Use

PyraSight is intended for academic demonstration, research, experimentation, and wildfire-related decision-support exploration.

It must not be used as the sole basis for emergency decisions, evacuation decisions, or official wildfire warnings.
